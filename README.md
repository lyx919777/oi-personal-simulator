
# OI 个人模拟器 （oi-personal-simulator）

> 一款基于 CCF NOI 大纲的单页 HTML 信息学竞赛模拟游戏

## 🎮 游戏简介

OI 个人模拟器是一款模拟信息学奥赛选手完整生涯的文字策略游戏。从 CSP-S 开始，一步步晋级到 NOIP、省选、NOI、CTSC，最终冲击 IOI 金牌！

## ✨ 核心特性

### 📚 基于 CCF NOI 大纲 2025 版

- **入门级（难度 1-5）**：基础语法、数据结构入门、基础算法
- **提高级（难度 5-8）**：线段树、动态规划进阶、图论算法
- **NOI 级（难度 7-10）**：高级数据结构、网络流、后缀自动机等

### 🏆 真实比赛晋级路线

```
CSP-S初赛 → CSP-S复赛 → NOIP → 省选 → NOI → CTSC → IOI
```

每场比赛题目都关联具体知识点，分数计算基于选手对知识点的掌握程度。

### 👨‍🏫 教练系统

5 位风格各异的教练：
- **张老师**：严格型，专长数据结构、DP
- **李老师**：温和型，专长图论、数学
- **王教练**：放养型，资源丰富
- **陈学长**：朋友型，全能
- **???**：神秘教练，需要解锁

### 🎁 礼物系统

- 6 大类 24 种礼物
- 每位教练有喜好偏好
- 送喜欢的礼物有额外加成

### 📊 训练系统

- **专题训练**：数据结构、图论、字符串、DP、数学
- **洛谷刷题**：入门/普及/提高/省选题库
- **网上赛事**：Codeforces、AtCoder 等
- **教练集训**：5 种集训项目，需达到好感度要求

### 🎲 随机事件

- 正面事件：灵感爆发、AC 快感、父母支持等
- 负面事件：WA 怀疑人生、心态爆炸、压力过大等
- 特殊事件：解锁教练、奖学金、集训邀请等

### 🏅 成就系统

22 种成就，涵盖刷题、比赛、社交等多个方面。

## 🎯 分数计算机制

比赛得分基于知识点掌握度：

```
能力指数 = 掌握度 / (难度系数 × 10)

能力指数 ≥ 1.5 → 碾压，几乎满分
能力指数 ≥ 1.0 → 稳，高概率满分
能力指数 ≥ 0.7 → 有挑战
能力指数 < 0.7 → 困难
```

短板知识会显著影响总分（木桶效应）。

3. 无需网络，无需安装

## 🎮 操作说明

### 时间系统

- 每年 12 个月，每月 4 周
- 每次行动消耗 1-4 周不等
- 高中起点 3 年，初中起点 5 年

### Admin 控制台

按 **`~`** 键打开管理员控制台，可修改属性。

## 📈 游戏策略建议

1. **针对性训练**：优先提升短板知识点
2. **合理休息**：压力过高会影响比赛发挥
3. **维护教练关系**：高好感度解锁更好的集训项目
4. **比赛策略**：
   - 稳健策略：按顺序做题，风险低
   - 冲刺策略：先做难题，风险高但有额外收益
   - 保底策略：确保简单题，稳妥但上限低
